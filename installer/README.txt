SUSPECT MODE for Ready or Not
https://github.com/The-IOMIOU/suspection   (full guide, settings, troubleshooting)

You and your friends are the suspects. An armoured SWAT team breaches the building to take you down.

INSTALL (every player, same version)
  1. Double-click install.bat. It finds the game, or asks you to paste the game folder
     (Steam: right-click Ready or Not > Manage > Browse local files).
  2. Start Ready or Not and play co-op as usual. The host's settings decide the rules.
  Always install from this zip. Do not copy the ue4ss folder from someone else's game.

IN GAME
  F8              Suspect Mode menu (all settings). Arrow keys to change.
  Loadout screen  Suspect weapons + CHARACTER LOOK panel (arrow keys: body, head, gear)
  Ballistic shield next to a civilian = human shield (SWAT hold fire)
  F7 (host)       Mode on/off
  F9/F10/F11      Change body/head/gear during a mission

A ROUND
  Setup time (you can't be hurt), then SWAT breach. Kill the whole SWAT team to win.
  Protect the VIP civilian. Presets: standard, easy, hardcore, survival (F8 menu).

UNINSTALL
  Run uninstall.bat. The game is vanilla again; saves are never touched.

CRASH OR PROBLEM?
  Send ReadyOrNot\Binaries\Win64\ue4ss\UE4SS.log and the newest folder in
  %LOCALAPPDATA%\ReadyOrNot\Saved\Crashes\  (see TROUBLESHOOTING on the GitHub page).
